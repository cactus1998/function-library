# docs

本資料夾專門存放產品需求文件（PRD）。

## 命名規則

- 檔名：`PRD-<主題>.md`，主題使用 kebab-case，例如 `PRD-function-library.md`。
- 專案層級的 PRD 放在本資料夾根目錄。
- 單一功能展示的 PRD 也放本資料夾，檔名 `PRD-<slug>.md`，以 `/feature-spec <功能>` 產生。
